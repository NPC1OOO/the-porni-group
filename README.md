## 🚀 Quick Start & Local Development

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# Clone the repository
git clone https://github.com/NPC1OOO/the-porni-group.git
cd the-porni-group

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build & Tests
```bash
# Build optimized static distribution and standalone single-file bundle
npm run build

# Run automated data integrity and build verification test suite
npm test
```
